以模块方式组织 agent 进行工作

## 模块

将项目划分成多个模块，以文件夹为单位，如果存在 module.md 则说明该目录是一个模块
在项目根目录需要有一个 module.md 作为项目说明

**module.md**
module.md 需要具备以下结构：
1. 模块说明，详细说明模块的作用、涉及的功能
2. 子模块说明，说明有哪些子模块，简要介绍子模块，说明子模块相对路径
3. 属于本模块的文件、文件夹；属于子模块的文件夹

## agent

1. 应用启动后需要拉起一个主 agent 负责承接用户的所有对话
2. 主 agent 负责跟哪些模块对话或者分发任务
3. 每个模块对应一个 agent

## 模块隔离

1. 设置工作目录，设置一个 main 目录然后拉起主 agent
2. 根据 module.md 在内存建立模块树形图，拉起模块的时候拉取对应的模块文件、文件夹到工作目录中，每个模块的代码都放在对应的模块文件夹中，避免互相干扰

## 项目架构设计

需要分成多个独立系统：
1. 模块图，负责扫描 module.md 建立模块图
2. 模块结构展示，以树形或其他结构展示模块信息
3. 模块通信，提供用户与模块对应的 agent 通信功能；提供模块之间的通信功能
4. 模块管理，负责在工作目录创建模块目录并拉取代码，管理模块对应代码
